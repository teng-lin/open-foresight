# Security policy

Please report suspected vulnerabilities privately to the maintainer at
[teng.lin@gmail.com](mailto:teng.lin@gmail.com), the contact listed in the package
metadata. Use the subject “Open Foresight security report”. Do not open a public
issue or pull request containing an exploit, credentials, private documents,
meeting audio, or a personal profile database.

Include the affected version and operating system, a minimal reproduction using
synthetic data, expected and observed behavior, and the likely impact. Redact
account tokens and personal content from logs. If a reproduction requires a
sensitive artifact, describe it first and arrange a private transfer with the
maintainer.

The maintainer will coordinate investigation, a fix, and disclosure with the
reporter. There is no guaranteed response or remediation deadline. The current
main branch and latest release are the supported investigation targets; older
releases may require an upgrade. A public issue may be opened after the details
and disclosure timing have been agreed privately.
